# СЕМЕСТР 1: Анализ одной переменной

## 1. Пределы: взгляд через микроскоп

### 1.1. В чём интуитивный смысл?
Иногда в формулу нельзя подставить значение напрямую: например, получается деление на ноль $\left[\frac{0}{0}\right]$.  
**Предел** отвечает на вопрос: *«К какому значению неумолимо приближается результат, если мы подходим к точке на расстояние волоска?»*

```text
       f(x)
        ^
        |           o  <- Дырка в точке x = a! Функция там не определена.
   L ---+--------- *           Но с обеих сторон кривая уверенно идёт к уровню L.
        |        *   *
        |       *     *
        +------+-------+-----> x
             a-δ   a   a+δ
```

### 1.2. Определение по Коши ($\varepsilon$–$\delta$)
$$\lim_{x \to a} f(x) = L \iff \forall \varepsilon > 0 \; \exists \delta > 0 : \forall x \; (0 < |x - a| < \delta \implies |f(x) - L| < \varepsilon)$$

> [!tip] Перевод на человеческий язык
> Какую бы микроскопическую погрешность $\varepsilon$ (эпсилон) вокруг ответа $L$ вам ни задали, вы всегда сможете подобрать окрестность $\delta$ (дельта) вокруг точки $a$, внутри которой функция гарантированно попадет в заданный коридор.

### 1.3. Инструменты вычисления
1. **Первый замечательный предел:**
   $$\lim_{x \to 0} \frac{\sin x}{x} = 1$$
   *Смысл:* При бесконечно малых углах длина дуги окружности и длина синуса практически совпадают.
2. **Второй замечательный предел:**
   $$\lim_{x \to \infty} \left(1 + \frac{1}{x}\right)^x = e \approx 2.71828$$
   *Смысл:* Предел непрерывного сложного процента (роста капитала или колонии бактерий).

## 2. Производная: крутизна и скорость

### 2.1. Физический и геометрический смысл
* **Физика:** Если $s(t)$ — пройденное расстояние, то $s'(t)$ — показания спидометра в конкретную миллисекунду.
* **Геометрия:** Тангенс угла наклона касательной прямой к графику:

```text
 y ^                  / (касательная с наклоном k = tg α)
   |                 /
   |             *  /    f'(x₀) > 0 : функция растёт (подъём)
   |           *  /      f'(x₀) < 0 : функция убывает (спуск)
   |        *    /       f'(x₀) = 0 : вершина холма или дно ямы
   |     *      /  α
   +----+------+--------> x
              x₀
```

$$f'(x_0) = \lim_{\Delta x \to 0} \frac{f(x_0 + \Delta x) - f(x_0)}{\Delta x}$$

### 2.2. Уравнения касательной и нормали
* **Касательная:** $y - y_0 = f'(x_0)(x - x_0)$
* **Нормаль (перпендикуляр):** $y - y_0 = -\frac{1}{f'(x_0)}(x - x_0)$

### 2.3. Вторая производная: выпуклость
* $f''(x) > 0$ — график улыбается $\cup$ (вогнут вверх, удерживает воду).
* $f''(x) < 0$ — график грустит $\cap$ (выпукл вниз, вода стекает).
* $f''(x) = 0$ со сменой знака — **точка перегиба** (смена типа искривления).

## 3. Неопределенный интеграл: сборка целого

### 3.1. Интуиция
Интегрирование — операция, обратная дифференцированию. Если у нас есть показания спидометра за каждую секунду, интеграл восстанавливает формулу пройденного пути.

$$\int f(x)\,dx = F(x) + C, \quad \text{где } F'(x) = f(x)$$

Знак $+C$ обязателен: зная скорость, мы знаем форму движения, но не знаем начальную координату (старт мог быть из нулевого километра или из сотого).

### 3.2. Главные приёмы
1. **Интегрирование по частям:**
   $$\int u \, dv = uv - \int v \, du$$
   *Мнемоника:* «Перебросить дифференцирование с неудобного множителя на удобный».
2. **Замена переменной (подведение под дифференциал):**
   $$\int f(g(x))g'(x)\,dx = \int f(u)\,du, \quad \text{где } u = g(x)$$

# СЕМЕСТР 2: Анализ в пространстве, интегралы и ряды

## 4. Определенный интеграл и геометрия

### 4.1. Суммы Римана
Площадь криволинейной трапеции разбивается на частокол из бесконечно тонких прямоугольников шириной $dx$ и высотой $f(x)$:

```text
 y ^
   |        __---''*''---__       Кривая y = f(x)
   |      /|   |   |   |   |\
   |     | | | | | | | | | | |    Сумма площадей полосок:
   |     | | | | | | | | | | |    S ≈ Σ f(xᵢ) · Δx
   +-----+-------------------+--> x
         a                   b
           <- dx ->
```

$$\int_a^b f(x)\,dx = \lim_{\Delta x \to 0} \sum_{i=1}^n f(x_i)\Delta x = F(b) - F(a) \quad \text{(Формула Ньютона — Лейбница)}$$

### 4.2. Приложения определенного интеграла
* **Площадь между кривыми:** $S = \int_a^b (f_{\text{верх}}(x) - f_{\text{низ}}(x))\,dx$
* **Объем тела вращения вокруг оси $OX$:** $V_x = \pi \int_a^b f^2(x)\,dx$
* **Длина дуги кривой:** $L = \int_a^b \sqrt{1 + (f'(x))^2}\,dx$

## 5. Функции нескольких переменных (ФНП)

### 5.1. Рельеф местности $z = f(x, y)$
Когда переменных две, график превращается из плоской линии в 3D-поверхность с холмами, оврагами и седловинами.

```text
             z (высота)
             ^
             |       * (вершина холма)
             |     /   \
             |    /  .  \   <- Поверхность z = f(x, y)
             |   /   |   \
             +---|---|---|-----> y
            /    \___|___/
           /         (x₀, y₀)
          v x
```

### 5.2. Частные производные
* $\frac{\partial z}{\partial x}$: «Замораживаем» координату $y$ (считаем её константой) и смотрим наклон склона строго при движении вдоль оси $X$.
* $\frac{\partial z}{\partial y}$: «Замораживаем» $x$ и смотрим наклон вдоль оси $Y$.

### 5.3. Градиент: компас экстремала
$$\nabla z = \operatorname{grad} z = \left( \frac{\partial z}{\partial x}, \; \frac{\partial z}{\partial y} \right)$$
* **Свойства градиента:**
  1. Вектор градиента лежит на плоскости аргументов $(x, y)$ и указывает направление **наиболее крутого подъёма** на холм.
  2. Длина вектора $|\nabla z|$ равна максимальной крутизне этого подъёма.
  3. Вектор градиента всегда перпендикулярен линиям уровня (горизонталям на топографической карте).

## 6. Числовые и степенные ряды

### 6.1. Сходимость: сумма бесконечного числа слагаемых
$$\sum_{n=1}^\infty a_n = a_1 + a_2 + a_3 + \dots$$

> [!example] Парадокс разрезанного торта
> Сложим бесконечный ряд:
> $$\frac{1}{2} + \frac{1}{4} + \frac{1}{8} + \frac{1}{16} + \dots = 1$$
> Вы берете половину торта, затем половину остатка, затем половину нового остатка... Слагаемых бесконечно много, но сумма никогда не превысит целый торт. Ряд **сходится**.

* **Необходимый признак сходимости:** если $\lim_{n \to \infty} a_n \neq 0$, то ряд заведомо расходится.

### 6.2. Признаки сходимости для положительных рядов
* **Признак Даламбера:** Считаем $D = \lim_{n \to \infty} \frac{a_{n+1}}{a_n}$.
  * $D < 1 \implies$ ряд сходится быстро (как убывающая геометрическая прогрессия).
  * $D > 1 \implies$ расходится.
  * $D = 1 \implies$ признак бессилен, требуется другой тест.
* **Признак Лейбница (для знакочередующихся рядов $\sum (-1)^n b_n$):**  
  Если члены монотонно убывают по модулю ($b_{n+1} \le b_n$) и стремятся к нулю ($b_n \to 0$), то ряд сходится.

# ЛИНЕЙНАЯ АЛГЕБРА И АНАЛИТИЧЕСКАЯ ГЕОМЕТРИЯ

## 7. Векторы и геометрия в пространстве

### 7.1. Виды произведений векторов
1. **Скалярное произведение ($\vec{a} \cdot \vec{b}$):**  
   $$\vec{a} \cdot \vec{b} = |\vec{a}| |\vec{b}| \cos \varphi = x_1 x_2 + y_1 y_2 + z_1 z_2$$
   *Результат — число.* Показывает, насколько векторы сонаправлены. Если $\vec{a} \cdot \vec{b} = 0$, векторы строго перпендикулярны.
2. **Векторное произведение ($\vec{a} \times \vec{b}$):**  
   *Результат — новый вектор*, перпендикулярный обоим исходным. Его длина равна площади параллелограмма, натянутого на $\vec{a}$ и $\vec{b}$. Направление определяется правилом правого винта:

```text
       c = a × b
           ^
           |   b
           |  /
           | /  φ
           +---------> a
        (вектор c смотрит вверх, перпендикулярно плоскости векторов a и b)
```

$$\vec{a} \times \vec{b} = \begin{vmatrix} \vec{i} & \vec{j} & \vec{k} \\ x_a & y_a & z_a \\ x_b & y_b & z_b \end{vmatrix}$$

## 8. Матрицы, определители и СЛАУ

### 8.1. Что такое матрица?
Матрица $A$ размера $m \times n$ — это не просто таблица чисел, а **оператор преобразования пространства**: она растягивает, поворачивает или сминает базисные векторы.

### 8.2. Определитель ($\det A$)
Определитель квадратной матрицы показывает **коэффициент масштабирования объема/площади** при данном преобразовании:
* Если $\det A = 2$, пространство растянулось по объёму в 2 раза.
* Если $\det A = 1$, объемы сохраняются (чистый поворот).
* Если $\det A = 0$, пространство «схлопнулось» (3D превратилось в плоскость или отрезок), система уравнений вырождена, обратной матрицы не существует.

$$\begin{vmatrix} a & b \\ c & d \end{vmatrix} = ad - bc$$

### 8.3. Решение СЛАУ методом Гаусса
Метод последовательного исключения переменных: приводим расширенную матрицу системы к ступенчатому виду с помощью элементарных строк:
1. Вычитаем из нижних строк верхние с нужными коэффициентами (обнуляем элементы под главной диагональю).
2. Двигаемся обратно снизу вверх, находя переменные одну за другой.
