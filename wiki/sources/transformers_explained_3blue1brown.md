## 🗺️ Общий поток данных в трансформере (Data Flow)

```
[Текст/Промпт]
      │
      ▼
[Токенизация] ──► Разбиение на токены (слова/куски слов)
      │
      ▼
[Embedding Matrix ($W_E$)] ──► Превращение токенов в векторы размерности $d_{model}$
      │
      ▼
┌─────────────────────────────────────────────────────────────┐
│ Повторяющийся блок трансформера (N слоев)                   │
│                                                             │
│  ┌───────────────────────┐                                  │
│  │   Attention Block     │ ◄── Векторы «общаются» и         │
│  │ (Механизм внимания)   │     впитывают контекст           │
│  └──────────┬────────────┘                                  │
│             ▼                                               │
│  ┌───────────────────────┐                                  │
│  │ MLP / Feed-Forward    │ ◄── Параллельная обработка       │
│  │        Layer          │     каждого вектора по отдельности│
│  └───────────────────────┘                                  │
└─────────────────────────────┬───────────────────────────────┘
                              ▼
        [Финальный вектор последнего токена в контексте]
                              │
                              ▼
        [Unembedding Matrix ($W_U$)] ──► Преобразование в логиты (размер словаря)
                              │
                              ▼
        [Softmax с температурой $T$] ──► Распределение вероятностей
                              │
                              ▼
        [Сэмплирование] ──► Новый токен ──► Добавление в контекст (повтор цикла)
```

## 📑 Полное содержание по таймкодам

### ⏱️ [00:00:00] — Введение: Что означает GPT?
- **GPT = Generative Pre-trained Transformer:**
  - **Generative:** Модель генерирует новый текст.
  - **Pre-trained:** Предварительно обучена на огромном корпусе данных с возможностью дальнейшей донастройки (fine-tuning).
  - **Transformer:** Конкретная архитектура нейросетей, представленная Google в 2017 году (изначально для машинного перевода).
- **Принцип авторегрессии:** Модель решает одну базовую задачу — по заданному фрагменту текста предсказывает распределение вероятностей для следующего токена.
- Повторяя цикл «предсказал токен $\rightarrow$ добавил в контекст $\rightarrow$ снова предсказал», модель генерирует связные эссе, диалоги и истории.

---

### ⏱️ [00:03:04] — Общий обзор архитектуры и прохождения данных
1. **Токенизация (Tokenization):** Текст разбивается на частицы — токены (слова, морфемы, знаки препинания).
2. **Векторизация (Embeddings):** Каждый токен превращается в числовой вектор высокой размерности.
3. **Attention Blocks (Блоки внимания):** Позволяют векторам взаимодействовать между собой и передавать информацию (слово *«модель»* в сочетании *«fashion model»* и *«ML model»* получает разный контекстный смысл).
4. **MLP / Feed-Forward Layers:** Обрабатывают каждый вектор независимо и параллельно (интуиция: длинный опросник признаков для обновления информации).
5. **Выходная проекция:** Смысл всего контекста аккумулируется в векторе последнего токена, который проецируется на весь словарь через матрицу деэмбеддинга.

---

### ⏱️ [00:06:37] — Парадигма Deep Learning и подсчет весов
- В отличие от классического программирования с жесткими правилами, глубокое обучение задает архитектуру с настраиваемыми параметрами (весами — **weights**).
- **Матрично-векторные умножения:** Практически все вычисления в LLM — это взвешенные суммы, упакованные в матрицы весов.
- **Масштаб GPT-3:**
  - 175 миллиардов обучаемых параметров.
  - Около 28 000 отдельных матриц, разбитых на 8 категорий.
  - Четкое разделение: **веса** (weights — «мозг» модели, полученный при обучении) vs **данные** (data — векторы промпта, обрабатываемые на лету).

---

### ⏱️ [00:12:32] — Векторные эмбеддинги (Word Embeddings) и семантическое пространство
- **Embedding Matrix ($W_E$):**
  - Размер словаря GPT-3: $V = 50\,257$ токенов.
  - Размерность вектора эмбеддинга: $d_{model} = 12\,288$.
  - Число параметров матрицы: $50\,257 \times 12\,288 \approx 617$ миллионов весов.
- **Геометрия смысла:**
  - Направления в многомерном пространстве кодируют смысловые свойства.
  - Векторная арифметика: $\vec{v}_{\text{woman}} - \vec{v}_{\text{man}} \approx \vec{v}_{\text{queen}} - \vec{v}_{\text{king}}$.
  - Взаимосвязи стран, лидеров, множественного числа.
- **Скалярное произведение (Dot Product):**
  - Мера выравнивания (сходства) двух векторов: $\vec{a} \cdot \vec{b} > 0$ при сонаправленности, $0$ при ортогональности, отрицательно при противоположных направлениях.

---

### ⏱️ [00:18:27] — Контекст и контекстное окно (Context Size)
- Начальный вектор из матрицы $W_E$ хранит лишь голое словарное значение слова.
- Проходя сквозь слои трансформера, вектор «впитывает контекст» (например, превращая слово *«King»* в *«король Шотландии из трагедии Шекспира Макбет»*).
- В GPT-3 длина контекста составляет $2048$ токенов: массив данных размером $2048 \times 12\,288$ чисел проходит через сеть целиком.

---

### ⏱️ [00:20:23] — Выходной слой: Unembedding Matrix ($W_U$)
- Для генерации следующего слова берется **последний вектор последовательности**.
- **Unembedding Matrix ($W_U$):** Проецирует $12\,288$-мерный вектор обратно в пространство размера словаря ($50\,257$ значений — нескорректированные оценки, или **логиты / logits**).
- Добавляет еще $\approx 617$ миллионов параметров к общей модели.

---

### ⏱️ [00:22:24] — Функция Softmax и влияние температуры
- Превращает произвольные числа (логиты $z_i$) в строгое вероятностное распределение (все значения от 0 до 1, сумма равна 1):
  $$\text{Softmax}(z_i) = \frac{e^{z_i / T}}{\sum_j e^{z_j / T}}$$
- **Температура ($T$):**
  - $T \to 0$: Аргмакс / детерминированный выбор наиболее вероятного слова (сухой, предсказуемый текст).
  - Умеренная $T$ ($0.7 - 1.0$): Баланс креативности и связности.
  - Высокая $T$ ($> 1.5$): Равномерное распределение шансов, высокий риск бессвязной генерации (галлюцинаций/бреда).

## 💡 Итоговое резюме (Summary)

> [!summary] Ключевые выводы
> 1. **Механизм авторегрессии:** Любая текстовая LLM — это многократно вызванная статистическая функция предсказания следующего токена на основе распределения вероятностей.
> 2. **Эмбеддинги как координаты смысла:** Слова и токены живут в пространстве высокой размерности ($12\,288$ измерений у GPT-3), где геометрические направления отражают семантические концепции.
> 3. **Впитывание контекста:** Задача трансформера — с помощью блоков внимания (Attention) и полносвязных сетей (MLP) обогатить вектор последнего токена смыслом всего контекста.
> 4. **Матричные проекции ($W_E$ и $W_U$):**
>    - $W_E$: Превращает индекс токена в вектор признаков.
>    - $W_U$: Превращает итоговый контекстный вектор в оценки следующего слова (логиты).
> 5. **Softmax и температура:** Преобразуют сырые логиты в вероятности, где параметр $T$ управляет степенью случайности и креативности модели.
