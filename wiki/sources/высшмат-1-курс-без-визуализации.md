## 1. Теория пределов и непрерывность

### 1.1. Определения пределов
* **Предел функции по Коши ($\varepsilon$–$\delta$):**
  $$\lim_{x \to a} f(x) = b \iff \forall \varepsilon > 0 \; \exists \delta > 0 : \forall x \; (0 < |x - a| < \delta \implies |f(x) - b| < \varepsilon)$$
* **Предел последовательности:**
  $$\lim_{n \to \infty} x_n = a \iff \forall \varepsilon > 0 \; \exists N : \forall n > N \; (|x_n - a| < \varepsilon)$$
* **Связь предела с б.м. величинами:**
  $$\lim_{x \to a} f(x) = b \iff f(x) = b + \alpha(x), \quad \text{где } \lim_{x \to a} \alpha(x) = 0$$

---

### 1.2. Замечательные пределы
> [!tip] Первый замечательный предел
> $$\lim_{x \to 0} \frac{\sin x}{x} = 1$$
> **Следствия:**
> * $\lim_{x \to 0} \frac{\operatorname{tg} x}{x} = 1$
> * $\lim_{x \to 0} \frac{\arcsin x}{x} = 1$
> * $\lim_{x \to 0} \frac{1 - \cos x}{x^2} = \frac{1}{2}$

> [!tip] Второй замечательный предел
> $$\lim_{n \to \infty} \left(1 + \frac{1}{n}\right)^n = e \quad \Longleftrightarrow \quad \lim_{x \to 0} (1 + x)^{\frac{1}{x}} = e$$
> **Следствия:**
> * $\lim_{x \to 0} \frac{\ln(1 + x)}{x} = 1$
> * $\lim_{x \to 0} \frac{e^x - 1}{x} = 1$
> * $\lim_{x \to 0} \frac{(1 + x)^\alpha - 1}{x} = \alpha$

---

### 1.3. Эквивалентные бесконечно малые при $x \to 0$
* $\sin x \sim x$
* $\operatorname{tg} x \sim x$
* $\arcsin x \sim x$
* $\operatorname{arctg} x \sim x$
* $1 - \cos x \sim \frac{x^2}{2}$
* $e^x - 1 \sim x$
* $\ln(1 + x) \sim x$
* $(1 + x)^\alpha - 1 \sim \alpha x$

---

### 1.4. Непрерывность и классификация разрывов
Функция $f(x)$ непрерывна в точке $x_0$, если:
$$\lim_{x \to x_0} f(x) = f(x_0) \quad \Longleftrightarrow \quad \lim_{\Delta x \to 0} \Delta y = 0$$

* **Разрыв I рода:** Односторонние пределы $f(x_0 - 0)$ и $f(x_0 + 0)$ конечны.
  * *Устранимый разрыв:* $f(x_0 - 0) = f(x_0 + 0) \neq f(x_0)$.
  * *Скачок (конечный разрыв):* $f(x_0 - 0) \neq f(x_0 + 0)$, величина скачка $h = f(x_0 + 0) - f(x_0 - 0)$.
* **Разрыв II рода:** Хотя бы один из пределов $f(x_0 \pm 0)$ равен $\infty$ или не существует.

## 2. Дифференциальное исчисление функции одной переменной

### 2.1. Определение и геометрический смысл
$$f'(x_0) = \lim_{\Delta x \to 0} \frac{f(x_0 + \Delta x) - f(x_0)}{\Delta x}$$
* **Касательная:** $y - y_0 = f'(x_0)(x - x_0)$
* **Нормаль:** $y - y_0 = -\frac{1}{f'(x_0)}(x - x_0)$
* **Дифференциал:** $dy = f'(x)dx$ (главная линейная часть приращения)

---

### 2.2. Правила дифференцирования
* $(u \pm v)' = u' \pm v'$
* $(uv)' = u'v + uv'$
* $\left(\frac{u}{v}\right)' = \frac{u'v - uv'}{v^2}$
* **Сложная функция:** $(f(g(x)))' = f'_u(u) \cdot g'_x(x)$
* **Обратная функция:** $x'_y = \frac{1}{y'_x}$
* **Параметрическая функция** $\begin{cases} x = \varphi(t) \\ y = \psi(t) \end{cases}$:
  $$y'_x = \frac{y'_t}{x'_t}, \qquad y''_{xx} = \frac{(y'_x)'_t}{x'_t}$$
* **Формула Лейбница для $(uv)^{(n)}$:**
  $$(uv)^{(n)} = \sum_{k=0}^n C_n^k u^{(n-k)} v^{(k)}$$

---

## 3. Теоремы дифференциального исчисления

> [!note] Основные теоремы анализа
> * **Теорема Ферма:** Если $x_0$ — точка локального экстремума и существует $f'(x_0)$, то $f'(x_0) = 0$.
> * **Теорема Ролля:** Если $f(x)$ непрерывна на $[a, b]$, дифференцируема на $(a, b)$ и $f(a) = f(b)$, то $\exists c \in (a, b): f'(c) = 0$.
> * **Теорема Лагранжа:** $f(b) - f(a) = f'(c)(b - a), \quad c \in (a, b)$.
> * **Теорема Коши:** $\frac{f(b) - f(a)}{g(b) - g(a)} = \frac{f'(c)}{g'(c)}, \quad c \in (a, b)$.

* **Правило Лопиталя:** Для неопределенностей вида $\left[\frac{0}{0}\right]$ или $\left[\frac{\infty}{\infty}\right]$:
  $$\lim_{x \to a} \frac{f(x)}{g(x)} = \lim_{x \to a} \frac{f'(x)}{g'(x)}$$

## 4. Формула Тейлора и разложения Маклорена

$$f(x) = \sum_{k=0}^n \frac{f^{(k)}(x_0)}{k!}(x - x_0)^k + r_n(x)$$
* В форме Пеано: $r_n(x) = o((x - x_0)^n)$
* В форме Лагранжа: $r_n(x) = \frac{f^{(n+1)}(c)}{(n+1)!}(x - x_0)^{n+1}$

### Разложения основных функций при $x \to 0$
$$e^x = 1 + x + \frac{x^2}{2!} + \dots + \frac{x^n}{n!} + o(x^n)$$
$$\sin x = x - \frac{x^3}{3!} + \frac{x^5}{5!} - \dots + (-1)^n \frac{x^{2n+1}}{(2n+1)!} + o(x^{2n+2})$$
$$\cos x = 1 - \frac{x^2}{2!} + \frac{x^4}{4!} - \dots + (-1)^n \frac{x^{2n}}{(2n)!} + o(x^{2n+1})$$
$$\ln(1 + x) = x - \frac{x^2}{2} + \frac{x^3}{3} - \dots + (-1)^{n-1} \frac{x^n}{n} + o(x^n)$$
$$(1 + x)^\alpha = 1 + \alpha x + \frac{\alpha(\alpha - 1)}{2!}x^2 + \dots + o(x)$$

## 5. Исследование функций

1. **Монотонность и экстремумы:**
   * $f'(x) > 0 \implies$ функция строго возрастает;
   * $f'(x) < 0 \implies$ функция строго убывает;
   * Смена знака $f'$ с $+$ на $-$ дает максимум, с $-$ на $+$ — минимум;
   * Если $f'(x_0) = 0$, а $f''(x_0) > 0 \implies \min$; если $f''(x_0) < 0 \implies \max$.
2. **Выпуклость и точки перегиба:**
   * $f''(x) > 0 \implies$ график вогнут (выпуклость направлена вниз $\cup$);
   * $f''(x) < 0 \implies$ график выпукл (выпуклость направлена вверх $\cap$);
   * Точка, в которой $f''(x)$ меняет знак — точка перегиба.
3. **Асимптоты:**
   * **Вертикальные:** $x = a$, если $\lim_{x \to a\pm 0} f(x) = \infty$.
   * **Наклонные:** $y = kx + b$, где:
     $$k = \lim_{x \to \pm\infty} \frac{f(x)}{x}, \qquad b = \lim_{x \to \pm\infty} [f(x) - kx]$$

## 6. Комплексные числа

* **Формы записи:**
  * Алгебраическая: $z = x + iy$
  * Тригонометрическая: $z = r(\cos\varphi + i\sin\varphi)$
  * Показательная: $z = r e^{i\varphi}$ ($r = \sqrt{x^2 + y^2}$, $\varphi = \operatorname{arg} z$)
* **Формула Муавра:**
  $$z^n = r^n (\cos n\varphi + i\sin n\varphi)$$
* **Извлечение корня степени $n$:**
  $$\sqrt[n]{z} = \sqrt[n]{r}\left(\cos\frac{\varphi + 2\pi k}{n} + i\sin\frac{\varphi + 2\pi k}{n}\right), \quad k = 0, 1, \dots, n-1$$

## 7. Неопределенный интеграл

### 7.1. Основные методы интегрирования
* **Интегрирование по частям:**
  $$\int u \, dv = uv - \int v \, du$$
* **Подведение под знак дифференциала (замена переменной):**
  $$\int f(\varphi(x))\varphi'(x)dx = \int f(\varphi(x))d\varphi(x) = \int f(u)du$$
